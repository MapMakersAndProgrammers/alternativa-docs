Packagealternativa.engine3d.animation
Classpublic class AnimationClip
InheritanceAnimationClip AnimationNode

Plays complex animation which is built from a set of animation tracks. For every distinct animated property of every model element there is a separate track needed. Track is somewhat similar to separate animated layer in Flash, but the layer stores full animation for some element. In opposite, track stores animation for every property (for an example, separate track for a scale and separate track for a coordinates). Track also can contain keyframes in arbitraty positions. Frames, contained between keyframes, are linearly interpolated (i.e. behave themselves like a timeline frames in flash, for which there is twin created ). Animation clip connects each track with a specific object. Animation clip stores information about animation for the whole model, i.e. for any element state at any time moment. Animation works with the help of AnimationController
