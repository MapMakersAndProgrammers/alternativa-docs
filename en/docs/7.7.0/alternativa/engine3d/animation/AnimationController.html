Packagealternativa.engine3d.animation
Classpublic class AnimationController

Controls animation playback and blending. I.e. it animates model using information stored in clips AnimationClip and generated by AnimationSwitcher and AnimationCouple blenders. You have to call method update() in frame refreshing controller, which refreshes all child animation clips and blenders, which return list of properties and values to controller after thah. You can use this list to set this properties. Controller sets this values and as a result the animation goes on. Animation control is carried out with the help of animated flag, and with AnimationSwitcher blender, which can transfer clip from active state to passive and vice versa.
