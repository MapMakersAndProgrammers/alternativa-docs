Packagealternativa.engine3d.animation.keys
Classpublic class NumberTrack
InheritanceNumberTrack Track

Track for numeric parameters animation. Key frames of NumberTrack have value property of type Number. Stores values of animated property in keyframes and make interpolation of property values in the intermediate moments of time.
