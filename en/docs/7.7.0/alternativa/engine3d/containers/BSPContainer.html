Packagealternativa.engine3d.containers
Classpublic class BSPContainer
InheritanceBSPContainer ConflictContainer Object3DContainer Object3D

Container which contains not only child objects but also binary structure - BSP-tree. You can build BSP-tree by calling method createTree() from polygons of supplied static geometry. BSP-tree consists of BSP-nodes. BSP-nodes contain polygons and objects. If node does not contain other nodes it calls leaf node. Otherwise nodes called inner. Inner nodes contain any numbers of polygons which places in single plain. Other child geometry are separated between branches of this node by what side of node polygons plane it placed . Leaf nodes contain static objects. Static objects get container as a parent, but they don't included to the child objects list so you can't remove them. Child objects added by addChild() are drawn taking into account BSP-tree. BSPContainer extends ConflictContainer so there are sort by partitioning algorithms in the final nodes of the tree.

createTree()method 
public function createTree(sourceGeometry:Vector, sourceSplitters:Vector = null, clearSource:Boolean = false, staticObjects:Vector = null):void

Creates BSP-tree of polygons supplied by static geometry. Old tree is destroyed. Static objects stay in the tree after creating.

Parameters
sourceGeometry:Vector — Mesh instances which faces are used to create BSP-tree. Vertices normals of supplied Mesh objects are stored in the BSPContaiter.
 
sourceSplitters:Vector (default = null) — Mesh instances, which faces serve as splitters. Splitters have higher priority than normal geometry, which means that they are closer to BSP-tree root. Splitters are not rendered.
 
clearSource:Boolean (default = false) — If true, vertices and faces are moved from source to the tree, otherwise their clones are created.
 
staticObjects:Vector (default = null) — Static objects.
