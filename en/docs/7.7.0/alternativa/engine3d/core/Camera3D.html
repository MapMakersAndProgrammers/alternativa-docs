Packagealternativa.engine3d.core
Classpublic class Camera3D
InheritanceCamera3D Object3D

Camera visualizes 3D objects hierarchy where it is situated. Camera has frustum created of four planes built through viewport and two planes built through near and far clipping distance. Frustum is necessary for excluding objects from drawing if they are not in a frustum. Render is provided to viewport — View. View direction is the same as Z axis of the camera direction.

diagramproperty 
diagram:DisplayObject  [read-only]

Diagram where debug information is displayed. To display diagra, you need to add it on the screen. FPS is an average amount of frames per second.
MS is an average time of executing the code part in milliseconds. This code part is measured with startTimer - stopTimer.
MEM is an amount of memory reserved by player (in megabytes).
DRW is an amount of draw calls in the current frame.
PLG is an amount of visible polygons in the current frame.
TRI is an amount of drawn triangles in the current frame.

calculateRay()method 
public function calculateRay(origin:Vector3D, direction:Vector3D, viewX:Number, viewY:Number):void

Calculates a ray in global space. The viewport of have to be set in order to perform calculations. The ray goes from the global camera position trough the point corresponding to the viewport point with coordinates viewX и viewY. This ray can be used in the Object3D.intersectRay() method.

Parameters
origin:Vector3D — Ray origin that lies on near clipping plane of the camera.
 
direction:Vector3D — Ray direction.
 
viewX:Number — Horizontal coordinate in viewport.
 
viewY:Number — Vertical coordinate in viewport.
