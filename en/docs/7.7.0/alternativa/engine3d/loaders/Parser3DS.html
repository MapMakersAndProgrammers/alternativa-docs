parentsproperty 
public var parents:Vector

List of parents for objects gotten in parsing result. It is possible to reconstruct hierarchy due to this list. Correspondence can be established by index. objects and parent length are equivalent. So for every n-th element of objects parent will be stored in n-th element of parent. Value will be set to null is there is no a parent of object.
