parse()method 
public function parse(data:XML, baseURL:String = null, trimPaths:Boolean = false):void

Parses xml Collada and fill lists: objects, parents, hierarchy, cameras, materials, textureMaterials, animations. MaterialLoader can be used to load texture materials. If some object contains other objects but is not container, container with same name will be created.

Parameters
data:XML — Collada xml.
 
baseURL:String (default = null) — Base URL to texture files. URL should correspond to URI specification. For example, file:///C:/test.dae or /C:/test.dae or test.dae or ./test.dae.
 
trimPaths:Boolean (default = false) — Base URL to texture files. URL should correspond to URI specification. For example, file:///C:/test.dae or /C:/test.dae or test.dae or ./test.dae.
