Property detail
defaultLightWeightproperty
public var defaultLightWeight:Number = 1

Influence weight of light sources for material by default. This value applies to sources that don't have value, specified by the setLightWeight() method. Light sources without specified value are ignored, if this value equals zero. Default value is 1.

multipliedDiffuseproperty 
public var multipliedDiffuse:Boolean = false

Flag of the texture, componentwisely premultiplied by 2. Lightning calculates using the given formula: result = 2iffuseight componentwisely. You can precalculate diffusion multiplication by 2 for a performance reasons, by drawing it to itself with BlendMode.ADD set to true. Default value is false.
