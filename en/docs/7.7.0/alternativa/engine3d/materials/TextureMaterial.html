resolutionproperty 
public var resolution:Number = 1

Texture resolution. Determines how many units of 3D space correspond to one pixel of texture. Value means anything only if code>mipMapping value equal to MipMapping.OBJECT_DISTANCE or MipMapping.PER_PIXEL. To calculate resolution of the specified object you can use its method calculateResolution().
