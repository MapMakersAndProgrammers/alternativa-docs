Packagealternativa.engine3d.objects
Classpublic class SkyBox
InheritanceSkyBox Mesh Object3D

Polygonal object like Box but its faces turned inside; it is not clipped by farClipping of Camera3D and it is possible to set texture coordinates transformation matrix.
